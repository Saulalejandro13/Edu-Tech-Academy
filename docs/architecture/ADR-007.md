# ADR-007 — Bitácora de auditoría inmutable

**Estado:** Aceptado.

## Contexto

EduTech Academy requiere trazabilidad sobre operaciones sensibles, especialmente:

- Modificación de calificaciones.
- Cambios de grupo.
- Sustitución de instructores.
- Autorizaciones administrativas.
- Emisión de certificados.

La ausencia de registros históricos dificultaría identificar responsables y justificar modificaciones.

## Decisión

Se establece una **bitácora de auditoría inmutable**.

El diseño contempla registrar:
- Usuario responsable.
- Fecha y hora.
- Operación realizada.
- Valor anterior.
- Valor nuevo.
- Usuario que autorizó el cambio, cuando corresponda.

Una vez registrado un acontecimiento, no debe modificarse su historial.

## Alternativas consideradas

- **Auditoría manual dentro de cada operación:** permite registrar cambios, pero puede generar implementaciones inconsistentes.
- **Triggers exclusivos de base de datos:** registran modificaciones, aunque pueden limitar la disponibilidad de información contextual del negocio.

## Consecuencias

**Ventajas:**
- Mayor trazabilidad.
- Facilita auditorías académicas y administrativas.
- Permite identificar modificaciones sensibles.
- Favorece la transparencia del sistema.

**Desventajas:**
- Aumenta la cantidad de información almacenada.
- Requiere proteger el acceso a los registros de auditoría.

## Evidencia de implementación

`src/edutech/infrastructure/db.py`

La aplicación incluye registros de auditoría mediante Unit of Work y una vista de consulta de bitácora.

La presencia de estos componentes no demuestra por sí sola la inmutabilidad absoluta ni que todos los eventos registren valores anteriores y nuevos. Esas garantías deben verificarse mediante pruebas.

## Trazabilidad

RNF-03, US-07, US-09, US-15, US-17 y US-18.
