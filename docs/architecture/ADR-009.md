# ADR-009 — Uso de consultas simples para operaciones de solo lectura

**Estado:** Aceptado.

## Contexto

No todas las operaciones de EduTech Academy requieren ejecutar comportamientos complejos del Domain Model.

Algunas funcionalidades consisten únicamente en consultar información, como:

- Catálogo de cursos.
- Pagos pendientes.
- Historial de operaciones.
- Consulta de bitácora.

Obligar a que todas estas operaciones utilicen agregados completos podría aumentar innecesariamente la complejidad y el costo de ejecución.

## Decisión

Se permite utilizar **consultas simples de solo lectura**, aplicando un enfoque ligero de Transaction Script o separación Command/Query cuando resulte apropiado.

Las operaciones que modifican información y ejecutan reglas complejas continúan utilizando el Domain Model.

## Alternativas consideradas

- **Utilizar Domain Model para todas las operaciones:** proporciona uniformidad, pero introduce complejidad innecesaria en consultas simples.

## Consecuencias

**Ventajas:**
- Menor complejidad.
- Menor sobrecarga de procesamiento.
- Consultas más directas.
- Separación entre lectura y operaciones de negocio.

**Desventajas:**
- No todas las operaciones utilizan el mismo estilo arquitectónico.
- Es necesario evitar que las consultas directas incorporen reglas de modificación del dominio.

## Evidencia de implementación

La aplicación utiliza consultas de lectura desde sus componentes de infraestructura y API.

El enfoque Command/Query se encuentra aplicado de manera parcial y no equivale a una arquitectura CQRS completa con almacenes separados.

## Trazabilidad

US-01, US-06, US-18 y Etapa 6 (Queries).
